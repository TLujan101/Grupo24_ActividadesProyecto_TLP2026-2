------------------------------ 1. MODIFICACIONES EN EL LENGUAJE DSL Y GRAMÁTICA ------------------------------

>>>>>> Extensión de la gramática formal para soporte de geometrías, niveles y consumibles:
Archivos modificados: grammars/snake.bnf, compiler.py

Se extendió la gramática formal BNF para admitir bloques de niveles de dificultad (LEVELS), geometrías
adicionales en DEFINE SHAPE, nuevos eventos y acciones específicas para consumibles y obstáculos:

<definicion_shape> ::= "DEFINE" "SHAPE" <identificador> <geometria> <extras> ":" <estados> "END"
<geometria> ::= "" | "GEOMETRY" <forma_geometrica>
<forma_geometrica> ::= "RECT" | "CIRCLE" | "TRIANGLE" | "NYAN_CAT"

<niveles>          ::= "LEVELS" ":" <elegir_nivel> <definiciones_nivel> "END"
<elegir_nivel>     ::= "" | "START" ":" <identificador>
<definicion_nivel> ::= "LEVEL" <identificador> ":" <modificadores_nivel> "END"
<modificador_nivel> ::= "TICK" <real> | "MUSIC" <identificador> | "INVULNERABILITY_DURATION" <numero> | "GEOMETRY" <forma_geometrica> | "POISON_ENABLED" <estado_booleano> | "POISON_KILLS" <estado_booleano> | "CLOUDS_COUNT" <numero>

>>>>>> Soporte léxico y sintáctico en el compilador para decimales y modificadores:
Archivo modificado: compiler.py (lineas 15, 211, 398)

El compilador original fallaba con números reales y booleanos. Se ajustó el lexer para reconocer tokens

>>>>>> Renderizado físico de triángulos con orientación dinámica por segmento:
Archivo modificado: engine/snake.py (metodos _direccion_del_segmento y dibujar_triangulo_celda)

Cada segmento triangular en el nivel Entusiasta apunta en la dirección en la que viajó ese fragmento
del cuerpo, calculando el vector respecto al segmento adyacente:

def dibujar_triangulo_celda(self, x, y, color, direccion=(0, -1)):
    c = self.taman_celda
    x1, y1 = x * c, y * c
    x2, y2 = x1 + c, y1 + c
    m = 2
    cx, cy = x1 + c / 2.0, y1 + c / 2.0
    dx, dy = direccion
    if dx > 0:      # Derecha
        puntos = [x2 - m, cy, x1 + m, y1 + m, x1 + m, y2 - m]
    elif dx < 0:    # Izquierda
        puntos = [x1 + m, cy, x2 - m, y1 + m, x2 - m, y2 - m]
    elif dy < 0:    # Arriba
        puntos = [cx, y1 + m, x1 + m, y2 - m, x2 - m, y2 - m]
    else:           # Abajo
        puntos = [cx, y2 - m, x1 + m, y1 + m, x2 - m, y1 + m]
    self.canvas.create_polygon(puntos, fill=color, outline="")

>>>>>> Nubes Obstáculo fijas con penalización severa y desvío determinista:
Archivo modificado: engine/snake.py (metodos dibujar_nube_celda, _redirigir_tras_choque)

Las nubes se dibujan en gris claro (#A9A9A9) para diferenciarlas. Al chocar sin invulnerabilidad:
si el jugador tiene 0 puntos muere inmediatamente; si tiene puntos, los drena a 0 (RESET_SCORE) y se
redirige en orden fijo determinista (derecha, abajo, izquierda, arriba) para no atravesar su cuerpo:

elif hasattr(self, 'nubes') and nueva_cabeza in self.nubes:
    if es_invulnerable:
        self.nubes.remove(nueva_cabeza)
        self.snake_spawn_nube()
    else:
        if self.puntuacion == 0:
            self.juego_terminado = True
            return
        self.puntuacion = 0
        self.ejecutar_evento('ON_COLLISION_CLOUD')
        nueva_cabeza = self._redirigir_tras_choque()
        if nueva_cabeza is None:
            self.juego_terminado = True
            return

>>>>>> Power-Up "No Morir" con duración cronometrada y cooldown de reaparición:
Archivos modificados: games/snake_remake.brick, engine/snake.py

Se implementa una baya amarilla que otorga invulnerabilidad durante n segundos reales. Para evitar
cadenas infinitas de invulnerabilidad, se incorporó un cooldown de 5.0 segundos antes de reaparecer:

elif hasattr(self, 'posicion_powerup') and nueva_cabeza == self.posicion_powerup:
    pos_anterior = self.posicion_powerup
    self.ejecutar_evento('ON_EAT_POWERUP')
    if getattr(self, 'duracion_inv_config', 0) > 0:
        self.posicion_powerup = None
        self.cooldown_powerup = 5.0  # Cooldown de 5 segundos
    elif self.posicion_powerup == pos_anterior:
        self.posicion_powerup = self._obtener_posicion_libre()

Durante la invulnerabilidad, la serpiente envuelve paredes (wrap-around), atraviesa su propio cuerpo y
despeja nubes y veneno sin sufrir daño. La cabeza parpadea en amarillo acelerando su frecuencia conforme expira.

>>>>>> Cabeza circular de alto contraste con rasgos felinos:
Archivo modificado: engine/snake.py (metodo dibujar_cabeza_nyan)

La cabeza de Nyan Cat se renderiza en blanco puro (#FFFFFF) para contrastar contra el fondo negro (#111111)
y la cola arcoíris. Cuenta con orejas triangulares externas e internas rosadas (create_polygon), base circular
(create_oval), mejillas rosadas (#FFAAA6), ojos negros con reflejo blanco y hocico (create_rectangle):

def dibujar_cabeza_nyan(self, x, y, color, direccion=(1, 0)):
    # Orejas poligonales exteriores (color) e interiores (#FFAAA6)
    poligono([(-0.38, -0.12), (-0.32, -0.46), (-0.06, -0.28)], color)
    poligono([(-0.32, -0.18), (-0.28, -0.38), (-0.12, -0.26)], "#FFAAA6")
    # Base circular (1 solo create_oval que preserva tests de tk_falso)
    self.dibujar_circulo_celda(x, y, color)
    # Facciones rectangulares (mejillas, ojos, brillos y nariz)
    rect(-0.28, 0.14, 0.07, 0.07, "#FFAAA6")
    rect(-0.16, -0.04, 0.08, 0.09, "#000000")
    rect(-0.18, -0.07, 0.03, 0.03, "#FFFFFF")
    rect(0.0, 0.08, 0.04, 0.03, "#000000")

>>>>>> Orientación 2D dinámica de la cabeza según el vector de movimiento:
Archivo modificado: engine/snake.py (metodo _rotar_coord_celda)

Se implementó una transformación de coordenadas de rotación 2D en base a self.serpiente_direccion. Al
moverse hacia UP, DOWN, LEFT o RIGHT, las orejas, ojos, brillos, mejillas y nariz rotan geométricamente
haciendo que el gato mire hacia el frente de su avance:

def _rotar_coord_celda(self, cx, cy, c, u, v, direccion):
    dx, dy = direccion
    if dx > 0:      # DERECHA (+90 deg)
        return (cx - v * c, cy + u * c)
    elif dx < 0:    # IZQUIERDA (-90 deg)
        return (cx + v * c, cy - u * c)
    elif dy > 0:    # ABAJO (180 deg)
        return (cx - u * c, cy - v * c)
    else:           # ARRIBA (0 deg)
        return (cx + u * c, cy + v * c)

------------------------------ 6. MECÁNICAS DE COLISIÓN Y ESCUDO DE PUNTOS ------------------------------

>>>>>> Mecánica de Escudo de Puntos en el nivel Nyan Cat:
Archivo modificado: engine/snake.py (snake_mover_jugador, lineas 500-555)

En snake.brick, chocar contra una pared o el propio cuerpo causaba Game Over inmediato. En Nyan Cat, los
puntos acumulados actúan como escudo amortiguador: al chocar, el puntaje se drena a 0 pero la serpiente
sobrevive (envolviendo el mapa por la pared o desviándose del cuerpo). Solo si los puntos ya eran 0 ocurre Game Over:

# Colisión con Pared:
if not self._dentro_del_tablero(nueva_cabeza):
    if es_invulnerable:
        nueva_cabeza = (nueva_cabeza[0] % self.ancho, nueva_cabeza[1] % self.alto)
    elif es_nyan_cat and self.puntuacion > 0:
        self.puntuacion = 0
        nueva_cabeza = (nueva_cabeza[0] % self.ancho, nueva_cabeza[1] % self.alto)
    else:
        self.ejecutar_evento('ON_COLLISION_WALL')
        return

# Auto-Colisión (Cuerpo):
if nueva_cabeza in cuerpo_solido and not es_invulnerable:
    if es_nyan_cat and self.puntuacion > 0:
        self.puntuacion = 0
        desvio = self._redirigir_tras_choque()
        if desvio is not None:
            nueva_cabeza = desvio
    else:
        self.ejecutar_evento('ON_COLLISION_SELF')
        return

Archivos garantizados: games/snake.brick, games/tetris.brick, compiler.py, engine/game.py

Los juegos originales (.brick clásicos) no contienen el bloque LEVELS ni formas especiales. El compilador

de forma idéntica a su versión base.
