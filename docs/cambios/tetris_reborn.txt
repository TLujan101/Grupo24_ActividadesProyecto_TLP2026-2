>>>>>> Condición de aparición de Power-Ups en engine/tetris.py (tetris_limpiar_lineas, lineas 224-249):

Solo un triple (3 o más líneas simultáneas) deja un Power-Up pendiente para el
siguiente SPAWN. Simple/doble solo dan puntaje. Hay un sorteo con 20% de
probabilidad de que no aparezca nada aun cumpliendo la condición:

if lineas_limpias >= 3:
    eleccion = random.random()
    if eleccion < 0.25:
        candidato = 'POWERUP'
    elif eleccion < 0.45:
        candidato = 'CLEAR_LINE_PIECE'
    elif eleccion < 0.65:
        candidato = 'SUPERBOMBA'
    elif eleccion < 0.80:
        candidato = "CLEAR_THREE_PIECE"
    else:
        candidato = None
    # Solo vale si el .brick define esa forma; si no, no hay premio
    # (así tetris.brick original nunca rompe el spawn).
    if candidato in self.datos_juego['shapes']:
        self.siguiente_powerup = candidato
        self.mostrar_notificacion_powerup(self.siguiente_powerup)

>>>>>> Efectos de cada Power-Up en engine/tetris.py (tetris_fijar_pieza y tetris_aplicar_gravedad):

Cada forma especial se detecta por nombre al fijarse y aplica su efecto en vez
de pintar celdas normales: POWERUP borra radio 3x3 (+150 pts, dispara
ON_EXPLOSION), SUPERBOMBA borra radio 5x5 (+350 pts, dispara ON_EXPLOSION),
CLEAR_LINE_PIECE vacía las filas ocupadas (+200 por fila) y CLEAR_THREE_PIECE
vacía las columnas ocupadas (+250 por columna). Tras borrar por explosión o
por columnas, las celdas que quedan flotando caen por gravedad
(tetris_aplicar_gravedad en el mismo archivo: compacta cada columna hacia
abajo conservando el orden).

>>>>>> Probabilidad ponderada por CHANCE en engine/utilidades.py (lineas 21-32):

Se usa solo stdlib (random + bisect, válido en Python 2.7, sin numpy):

def eleccion_ponderada(items, pesos):
    if len(items) != len(pesos):
        raise ValueError("items y pesos deben tener la misma longitud")
    acum = []
    s = 0
    for w in pesos:
        s += w
        acum.append(s)
    if s <= 0:
        raise ValueError("Los pesos deben sumar > 0")
    tiro = random.randint(1, s)
    return items[bisect.bisect_left(acum, tiro)]

El pool se arma en engine/tetris.py (inicializar_estado, lineas 16-34):
cada SHAPE aporta su CHANCE (10 por defecto si el JSON es viejo) y POWERUP se
excluye del sorteo normal. El color se resuelve en tetris_spawn_pieza
(lineas 87-109) leyendo el JSON: Colores.get(Datos.get("color", "CYAN")).
