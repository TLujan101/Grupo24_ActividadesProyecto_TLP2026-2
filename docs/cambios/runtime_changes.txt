2. Sorteo ponderado por CHANCE (nuevo, en engine/utilidades.py lineas 21-32)

Antes el spawn era uniforme, todas las piezas salian con igual probabilidad:

>   nombre_pieza = random.choice(self.datos_juego['shapes'].keys())

Ahora la eleccion respeta el CHANCE de cada pieza.
Se usa bisect (solo stdlib, sin numpy) con esta funcion auxiliar:

import bisect

def eleccion_ponderada(items, pesos):
    if len(items) != len(pesos):
        raise ValueError("items y pesos deben tener la misma longitud")
    acum = []
    s = 0
    for w in pesos:
        s += w
        acum.append(s)
    if s <= 0:
        raise ValueError("Los pesos deben sumar > 0")
    tiro = random.randint(1, s)
    return items[bisect.bisect_left(acum, tiro)]


3. Pool de piezas en inicializar_estado (nuevo, en engine/tetris.py lineas 16-34)

El pool se arma una sola vez al crear el juego: dos listas paralelas
(_nombres_piezas, _pesos_piezas) con el CHANCE de cada SHAPE.

POWERUP se excluye del sorteo normal.
Solo sale como premio (ver punto 6).

Si un shape viene en formato viejo (lista, sin diccionario)
se usa chance 10 por defecto.
Asi tetris.brick original sigue funcionando sin cambios:

for NombrePool in self.datos_juego['shapes'].keys():
    if NombrePool == 'POWERUP':
        continue
    DatosPool = self.datos_juego['shapes'][NombrePool]
    if isinstance(DatosPool, dict):
        PesoPool = int(DatosPool.get('chance', 10))
    else:
        PesoPool = 10
    self._nombres_piezas.append(NombrePool)
    self._pesos_piezas.append(PesoPool)

5. Efectos de Power-Up al fijar la pieza (nuevo, en engine/tetris.py lineas 132-211)

tetris_fijar_pieza detecta la pieza por nombre y aplica su efecto en vez de
pintar celdas normales:
- POWERUP: borra radio 3x3 alrededor (+150 pts, dispara ON_EXPLOSION).
- SUPERBOMBA: borra radio 5x5 (+350 pts, dispara ON_EXPLOSION).
- CLEAR_LINE_PIECE: vacia las filas ocupadas (+200 por fila).
- CLEAR_THREE_PIECE: vacia las columnas ocupadas (+250 por columna).
Toda pieza fijada dispara ON_PIECE_LAND y luego ON_START (siguiente spawn).

tetris_limpiar_lineas: antes solo disparaba ON_LINE_CLEAR por linea.
Ahora, si son 3 o mas simultaneas (triple), sortea un Power-Up para el
proximo spawn (con 20% de probabilidad de nada):

if lineas_limpias >= 3:
