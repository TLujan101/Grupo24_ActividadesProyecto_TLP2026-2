>>>>>> Se añade el cálculo de Probabilidad Ponderada haciendo uso de la librería Bisect:

def eleccion_ponderada(items, pesos):
    if len(items) != len(pesos):
        raise ValueError("items y pesos deben tener la misma longitud")
    acum = []
    s = 0
    for w in pesos:
        s += w
        acum.append(s)
    if s <= 0:
        raise ValueError("Los pesos deben sumar > 0")
    tiro = random.randint(1, s)
    return items[bisect.bisect_left(acum, tiro)]

------------------------------ ARQUITECTURA DEL MOTOR DE JUEGO ------------------------------ 

>>>>>> Se refactorizó por completo el archivo principal, pasando de ser un archivo monolítico a un diseño modular orientado a objetos:

Lógica detrás del cambio: El archivo original manejaba toda la lógica de todos los juegos simultáneamente (más de 500 líneas), dificultando la escalabilidad y mantenimiento. 
Se optó por una arquitectura modular donde una clase base maneja todo lo común (ventana, grid, input)

- Clase base estandarizada.
- Clases hijas contienen lógicas específicas de cada juego.
- Archivo de utilidades maneja las elecciones aleatorias ponderadas y paletas de colores.
- Archivo principal ahora funciona únicamente como un lanzador limpio.

Líneas clave en el lanzador principal (ahora es muy pequeño):
    try:

    except ValueError as e:

------------------------------ MEJORAS AL COMPILADOR ------------------------------ 

>>>>>> Se añadieron métodos para hacer el Parser más robusto y permitir lectura de parámetros avanzados:

Lógica detrás del cambio: El compilador base crasheaba si los archivos no terminaban de la forma esperada o si había un tipo de dato incorrecto (ej. letras donde iba un número). 
Se crearon funciones para "espiar" tokens sin consumirlos y para asegurar validaciones de tipo numérico.

Código clave añadido al Parser:
    def ver(self):
        # Proximo token o None si se acabo (evita IndexError en truncados)
        if self.posicion < len(self.tokens):
            return self.tokens[self.posicion]
        return None

    def consumir_numero(self):
        token = self.consumir()
        if token is None:
            raise Exception("Error de sintaxis: se esperaba un numero...")
        try:
            return int(token)
        except ValueError:
            raise Exception("Error de sintaxis...")
