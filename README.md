## Jugar
Con Python 2.7, desde la raíz del repo:
```
jugar.bat tetris_reborn   (Windows, cmd.exe)
./jugar.sh tetris_reborn  (Linux)
```
Sin argumento muestra el menú de juegos en `games/`.
